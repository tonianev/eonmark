# M7-1: Esc pause menu and settings

Size M · Risk low · Lane G · Waits on: nothing (PLAN D1 allows it before M6 closes)

## Goal
[design/ui.md](../design/ui.md)'s pause menu. Esc in a live match opens a menu with Resume, UI scale, Volume, Borderless fullscreen and Quit to menu. The sim does not tick while it is open, and UI scale and volume persist.

## Steps
1. `PauseReason::Menu` already exists and already gates world input (`world_input_allowed`, wired into `hud::gate_world_input`); nothing sets it yet. The menu sets it on open and restores the previous value on close, so a Space pause (`PauseReason::Key`) survives a menu open and close.
2. Esc in normal order mode opens the menu and clears the selection (`clear_selection_on_escape` keeps clearing it). In attack-move or placement mode Esc only leaves the mode (`order_mode_keys`); a second Esc then opens the menu. Esc again, or Resume, closes it. Not available in `AppState::Menu` or after the outcome (`MatchOver`); available while spectating.
3. Rows, built from `menu/widgets.rs` (reuse `option_row` and `spawn_button`): UI scale 75, 100, 125 and 150 per cent through Bevy's `UiScale` resource; Volume 0 to 100 in steps of 10, stored now and applied by M7-3; Borderless fullscreen toggling `Window.mode` between `WindowMode::Windowed` and `WindowMode::BorderlessFullscreen(MonitorSelection::Current)` (never exclusive fullscreen); Quit to menu.
4. Quit to menu does what the game-over screen's Main Menu does: `commands.insert_resource(PendingMatch::MainMenu)` and `NextState<AppState>::set(AppState::Menu)`. The replay is finished by `match_scope` with its trailer; it must verify, ending at the current tick with no outcome.
5. `settings.rs`: `Settings { ui_scale_percent: u16, volume_percent: u16 }` stored as RON in the `directories` config directory of the project the replays already use. Read at startup, written on change. A missing or unreadable file gives the defaults (100, 80) and one `warn!`.
6. `--pause-menu-at-tick <n>` in `cli.rs` (usage text, parser, a unit test) opens the menu at an exact tick, like `--pause-at-tick`, for tests and the screenshot.
7. Strings go in `data/rules/strings/en.ron` (and `HUD_KEYS` in `economy_hud.rs` if the other `hud.*` keys are registered there; a missing key fails a test).
8. Docs: ui.md "Menus" (as built), PLAYTEST "Automated proxies (M7)" (new section, one row for this).
