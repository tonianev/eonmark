# M7-2: Vendor the Kenney UI, icons and audio

Size S to M · Risk medium · Lane A · Waits on: owner session O3 (kenney.nl answers HTTP 403 to scripted clients)

## Goal
The CC0 files M7-3 and M7-4 need are vendored with sha256 pins and `ATTRIBUTION.md` rows, and `scripts/check_assets.sh` (with `--self-test`) passes.

## Serves
M7 deliverable "Kenney UI Pack + Game Icons" and the audio clips. (The ART_STYLE sources table also allows Freesound; PLAN D11 picks Kenney's audio packs: one host, one licence file per pack.)

## Read first
PLAYBOOK P10 (assets and hosts). `docs/ART_STYLE.md`, "Allowed asset sources" and "Where the art pass's files come from".

## Anchors
- `tools/assets/sources.tsv`: `sha256`
- `scripts/fetch_assets.sh`: `sha256`
- `scripts/check_assets.sh`: `ATTRIBUTION`
- `assets/ATTRIBUTION.md`: `CC0-1.0`
- `tools/inspect_gltf/tests/repo.rs`: `attribution_rows_match_the_sources`

## Steps
1. Verified 2026-11-10: with the host allowed in the `eonmark` environment, `curl -sSI https://kenney.nl/assets/ui-pack` still returns `HTTP/2 403` from kenney.nl's own server (the proxy tunnel works; the site rejects scripted clients). **Do not work around it** (no spoofed User-Agent: the auto-mode classifier denies that, and it is the site's choice). The owner downloads the packs in a browser (PLAN O3) and pushes them to the branch `owner/kenney-inbox`; fetch them with `git fetch origin owner/kenney-inbox && git checkout origin/owner/kenney-inbox -- inbox/` (check first with `git ls-remote origin owner/kenney-inbox`: if it prints nothing the drop has not happened, so say so, leave the WP `waiting(O3)` and stop).
2. Unpack each zip into its own new directory outside the repo; treat it as untrusted data (read it with `python3 -I`, never run anything in it). Do not commit the inbox zips to your PR branch. Read the pack's licence file and require "CC0" before using a file. Packs (the owner downloads kenney.nl/assets/<slug>): `ui-pack` (or `ui-pack-rpg-expansion`, whose browns and beiges sit closer to the palette), `game-icons`, `interface-sounds`, `impact-sounds`, and `music-jingles` or `rpg-audio`.
3. Choose the files M7-3 and M7-4 use: about 10 panel, button and frame PNG files; about 8 icons (grain, lumber, ore, lore, move, attack, stop, annex); about 11 OGG cues (UI click, move, attack order, build placed, building complete, unit trained, research complete, age advanced, under attack, victory, defeat). Each file under 2 MB.
4. Extend `tools/assets/sources.tsv` and `scripts/fetch_assets.sh` with zip-member rows (zip URL, zip sha256, member path, file sha256). Read the script first and make the smallest change that fits it. The vendored copies are the source of truth.
5. Vendor (new directories) into `assets/ui/kenney_<pack>/`, `assets/icons/kenney_game_icons/` and `assets/audio/kenney_<pack>/`, each pack's licence text beside it with its own row. Write the `ATTRIBUTION.md` rows: asset, author (Kenney), source page URL, `CC0-1.0`, modifications `none`, download date.

## Verify
`scripts/check_assets.sh` and `scripts/check_assets.sh --self-test`; `cargo test -p inspect_gltf`; no file over 2 MB; `scripts/quick_check.sh`; `just ci`.

## Done when
CI green and M7-3 and M7-4 can name every file they need.

## Stop if
A pack has no CC0 licence text, or the host stays blocked and O3 has not happened. Leave the WP `waiting(O3)` and say so.
