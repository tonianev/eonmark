# M7-3: Audio

Size M · Risk low · Lane G · Waits on: M7-1 (the volume setting), M7-2 (the files)

## Goal
About ten CC0 cues through one facade, the volume from M7-1's setting, silent in every automated run.

## Anchors
- `crates/sim/src/state.rs`: `SimEvent`, `UnitSpawned`, `BuildingPlaced`, `BuildingCompleted`, `ResearchCompleted`, `AgeAdvanced`, `MatchDecided`
- `crates/game/src/sim_driver.rs`: `SimEventMsg`, `LOCAL_PLAYER`
- `crates/game/src/alert.rs`: `StyleHidden`
- `crates/game/src/background.rs`: `background`
- `crates/game/src/menu/widgets.rs`: `spawn_button`
- `crates/game/src/settings.rs` (new, from M7-1): `volume_percent`
- `crates/game/src/audio.rs` (new)

## Facts verified against Bevy 0.19.1
`audio` is in Bevy's default features, so `bevy_audio` and `vorbis` (OGG) are on already; `cargo tree -i cpal --depth 0` prints the one cpal version M7 line 5 wants. `AudioPlayer`, `PlaybackSettings::DESPAWN` and `GlobalVolume { volume: Volume }` (`Volume::Linear(f32)`) exist. Changing `GlobalVolume` does not affect sounds already playing; cues are short one-shots, so set it when the setting changes and spawn new cues after.

## Steps
1. `audio.rs`: `enum Cue { UiClick, OrderMove, OrderAttack, BuildPlaced, BuildingComplete, UnitTrained, ResearchComplete, AgeAdvanced, UnderAttack, Victory, Defeat }` and one table from cue to `assets/audio/...ogg` (the files M7-2 vendored).
2. `SfxPlugin` plays a cue on: a widget button press (`widgets::spawn_button`); an accepted human order (the same path that records a command); the local player's own sim events (`SimEvent::UnitSpawned` for an own trained unit, `BuildingPlaced`, `BuildingCompleted`, `ResearchCompleted`, `AgeAdvanced`: filter on the owner being `LOCAL_PLAYER`; an enemy's events make no sound); the existing under-attack alert (`alert.rs`); the outcome for the local player (a spectator hears Victory).
3. Each cue has a minimum interval of 200 ms (`Time<Real>`); `UnderAttack` follows the alert's own throttle.
4. `GlobalVolume` follows `Settings.volume_percent` (percent / 100 as `Volume::Linear`).
5. `--background` and a new `--mute` flag (cli.rs: usage, parser, unit test) silence everything, so agent runs on the owner's Mac stay quiet. Nothing in the sim reads audio.
6. Docs: ui.md "Audio"; ART_STYLE's asset rows; one line in STREAMING.md that OBS should capture the game's audio.
