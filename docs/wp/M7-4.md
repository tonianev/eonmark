# M7-4: Kenney panels and icons

Size M · Risk medium (visual judgement) · Lane G · Waits on: M7-2

## Goal
Menus, the HUD and the game-over screen use Kenney 9-slice panels (`NodeImageMode::Sliced`) tinted to the existing palette, plus resource and order icons, without breaking any fit test or the ART_STYLE checklist.

## Anchors
- `crates/game/src/menu/widgets.rs`: `spawn_button`, `option_row`, `button_color`
- `crates/game/src/palette.rs`: `team_color`
- `crates/game/src/economy_hud.rs`: `HUD_KEYS`
- `crates/game/src/outcome.rs`: `GameOverButton`
- `crates/game/src/command_card.rs`: `CardButton`, `CardGrid`
- `crates/game/src/minimap.rs`: `spawn_minimap`
- `docs/ART_STYLE.md`: `matte`

## Facts verified against Bevy 0.19.1
`NodeImageMode::Sliced(TextureSlicer)` is in `bevy_ui::widget::image`; `TextureSlicer` is in `bevy_sprite::texture_slice`. Load each image once into a `UiSkin` resource and tint the slices with the palette's panel colours (`ImageNode::with_color`).

## Rules
Every text and every palette colour stays. Panels replace flat rectangles only, and icons sit beside labels, never instead of them. Start in `menu/widgets.rs` (one change reskins both menus and the game-over screen), then the top bar (`economy_hud.rs`), the bottom bar and command card, the selection panel and the minimap frame. Keep the HUD matte (ART_STYLE: no glow, no gradients beyond the slices).

## Steps
1. Add `UiSkin` (loaded in a startup system, files from M7-2) and use it in `widgets.rs`.
2. Reskin the other panels one file at a time, running the fit tests after each.
3. Retake the screenshots that show the HUD (the `m6-*.png` set, via `scripts/m6_checks.sh`; `art-match-minimap.png` only if it changes, and then say in the PR that AP8's sign-off covers the new look). Read each PNG against the ART_STYLE checklist ("palette, no glow, readable at 40 m, matte HUD") and write the ticks into the PR.

## Tests
Every existing fit test passes unchanged. Add `panels_use_the_skin_and_keep_palette_tints` and `icons_do_not_change_label_text`.

## Verify
`scripts/quick_check.sh`; `just render-smoke` then `scripts/check_draws.sh <log>` (9-slice panels add draw calls: keep `art_bench` under 450 for headroom); `just ci`.

## Done when
CI green, screenshots read and committed, ui.md updated.

## Stop if
A fit test fails at 1280x720 and the fix is not local: ship the panels on the menus only and file the HUD part as an issue.
