# M7-6: Fog in the game

Size L · Risk medium (visual judgement) · Lane G · Waits on: M7-5

## Goal
The human sees fog: unexplored land black, explored land darkened (0.45), visible land lit. Enemy units vanish without friendly vision; the minimap darkens and filters its dots in the same frame. Spectating shows no fog. New Game gains the faction row and the bot-vision disclosure.

## Facts (verified 2026-11-08)
`field_texels` writes four bytes per tile `[owner code, strength, u8::MAX, 0]`: B is already 255 (visible) and unread. `sync_field` rewrites the image only when `field.sources()` changed; widen that test to the local player's grid. Bevy's mesh picking skips `Visibility::Hidden` entities by default; a test must still prove a hidden enemy cannot be selected or attacked.

## Steps
1. `field.rs`: `field_texels(field, fog: Option<&[u8]>)` writes B = 0 / 115 / 255 for states 0 / 1 / 2 (115/255 is 0.45); `None` writes 255 (spectating, tests). `sync_field` keeps a copy of the last grid written and rewrites when it or the sources changed (compare 16 KiB; cheap).
2. `field.wgsl`: after the territory tint and border mix in `fragment`, multiply `rgb` by the sampled B channel (the sampler already filters bilinearly, so the fog edge is one tile soft; judge it on the screenshot and record the choice in fog.md, whose open question this is).
3. `present.rs` and the keyed entities (health bars, selection rings, banners, minimap pings): an enemy unit is `Visibility::Hidden` unless its tile is state 2; an enemy building or site is hidden while its centre tile is state 0; hit effects draw only when the source or target is visible. Own things always draw. Use `SimView::tile_state(LOCAL_PLAYER, tile)`.
4. `minimap.rs`: a cached fog layer rebuilt when the grid changes (follow `sync_territory_layer`); enemy unit dots only on state 2, enemy building dots on state 1 or 2. Reuse the "repaints in the update of its tick" test pattern (`the_plugin_shows_a_new_border_in_the_update_of_its_tick`).
5. Orders: a click on fogged ground is a move; a hidden enemy is not pickable.
6. New Game (`menu/new_game.rs`): a faction row listing every faction in `factions.ron` (one today), the choice reaching the replay header (`MatchSetup.factions`). The disclosure string already exists: `menu.disclosure` ("The bot knows where your Seat is"), shown by `menu/main_menu.rs` and registered in `HUD_KEYS` (`economy_hud.rs`). Change its text in `en.ron` to say the bot sees the whole map (ADR 0004), and show the same line on the game-over screen (`outcome.rs`) beside the bonus row (a `game_over.disclosure` key if the layout needs its own; register it in `HUD_KEYS`).
7. Screenshots at 1280x720 from `--scenario fog_walkthrough --screenshot-at`: `docs/screenshots/m7_town.png` (new; P0's Town with explored and unexplored land in view), `m7-fog-minimap.png`, `m7-new-game.png`. Read each against the ART_STYLE checklist and write the ticks into the PR.
8. CI: add `fog_walkthrough` to game-linux's render smoke with the draw-call gate (`scripts/check_draws.sh`).
