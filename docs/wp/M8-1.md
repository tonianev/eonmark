## Steps
1. Pin every third-party action to a full commit SHA, keeping the version as a comment (`uses: actions/checkout@<sha> # v7`). Resolve each tag with `git ls-remote https://github.com/<owner>/<repo> '<tag>' '<tag>^{}'`, taking the `^{}` (peeled) SHA of an annotated tag. If github.com git access is refused from this environment, fetch the SHAs with the GitHub MCP `get_tag` or `get_commit`. Dependabot's github-actions updates keep the pins current.
2. Find a Dependabot grouped PR that passed CI (`list_pull_requests` with the Dependabot author). If none exists, say in the PR when the next weekly run is due (`day: monday` in dependabot.yml) and ask the owner to merge it once green.
3. Confirm each tool of the line runs in CI (`typos`, machete, deny, doc in `just ci` and ci.yml) and link a green run.

## Verify
`grep -n "uses:" .github/workflows/*.yml` shows only SHAs with version comments; CI green.
